
# Personal Profile Website – Hallo, I'm Bintang

## Deskripsi Project
Website profil pribadi sederhana yang dibuat untuk memperkenalkan diri.
Website ini merupakan project pembelajaran Web Application Development (WAD).

## Fitur Website
- Home: Halaman utama dan perkenalan.
- About Me: Informasi singkat tentang profil.
- Contact: Bagian informasi kontak.

## Teknologi yang Digunakan
- HTML5
- Tailwind CSS
- Git
- GitHub

## Tujuan Project
Project ini dibuat untuk mempelajari struktur HTML, penggunaan Tailwind CSS,
serta pengelolaan project menggunakan Git dan GitHub.

## Cara Menjalankan
1. Download atau clone repository ini.
2. Buka folder project di Visual Studio Code.
3. Buka file index.html melalui browser.
